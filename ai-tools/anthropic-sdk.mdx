# Anthropic SDK

The Anthropic SDK is the official library for building AI agents with Claude in your applications. By instrumenting your agents with Shinzo, you gain deep observability into agent behavior, including conversation traces, tool usage, token consumption, and performance metrics.

## How It Works

Shinzo provides observability for Anthropic SDK-based agents through two approaches:

1. **API Proxying**: Route SDK requests through Shinzo to capture conversation data automatically
2. **Telemetry Instrumentation**: Use Shinzo's OpenTelemetry wrappers to capture detailed traces

### Architecture Overview

```
Your Agent → Anthropic SDK → Shinzo Proxy → Anthropic API
                ↓
         Telemetry Data → Shinzo Platform → Dashboard
```

**What's captured**:
- Conversation flow (prompts, responses, context)
- Tool calls and results
- Token usage and costs
- Performance metrics (latency, throughput)
- Error traces and debugging information

## Prerequisites

Before you begin, ensure you have:

1. **A Shinzo account** - Sign up at [app.shinzo.ai](https://app.shinzo.ai)
2. **Your Anthropic API key** stored in Shinzo - Add it in **Settings > API Keys > Provider Keys**
3. **A Shinzo API key** - Create one in **Settings > API Keys > Shinzo Keys**
4. **The Anthropic SDK** installed:
   - [TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript)
   - [Python SDK](https://github.com/anthropics/anthropic-sdk-python)

**Subscription-Based Support**: Due to current platform architecture, agent observability has limitations with subscription-based Anthropic accounts (Claude Pro/Team with OAuth tokens).

## Setup Guide

### Option 1: Basic API Proxying (Quickest)

This approach routes your Anthropic SDK requests through Shinzo to capture conversation data automatically.

<Steps>
<Step title="Add your Anthropic API key to Shinzo">
  1. Go to [app.shinzo.ai](https://app.shinzo.ai)
  2. Navigate to **Settings > API Keys**
  3. Click the **Provider Keys** tab
  4. Click **Add Provider Key**
  5. Select **Anthropic** as the provider
  6. Paste your Anthropic API key from the [Anthropic Console](https://console.anthropic.com/settings/keys)
  7. Click **Save**

  <Check>
  Your key will be validated and encrypted before storage.
  </Check>
</Step>

<Step title="Create a Shinzo API key">
  1. In the **API Keys** page, click the **Shinzo Keys** tab
  2. Click **Create Key**
  3. Give your key a descriptive name (e.g., "Production Agent")
  4. Copy the generated key
</Step>

<Step title="Configure the Anthropic SDK">
  Initialize the Anthropic client with your Shinzo API key and base URL:

  <CodeGroup>
  ```typescript TypeScript
  import Anthropic from "@anthropic-ai/sdk";

  const anthropic = new Anthropic({
    apiKey: "sk_shinzo_live_your_key_here",
    baseURL: "https://api.app.shinzo.ai/spotlight/anthropic"
  });

  // Use the client normally
  const message = await anthropic.messages.create({
    model: "claude-sonnet-4-5",
    max_tokens: 1000,
    messages: [
      {
        role: "user",
        content: "Hello, Claude!"
      }
    ]
  });

  console.log(message.content);
  ```

  ```python Python
  import anthropic

  client = anthropic.Anthropic(
      api_key="sk_shinzo_live_your_key_here",
      base_url="https://api.app.shinzo.ai/spotlight/anthropic"
  )

  # Use the client normally
  message = client.messages.create(
      model="claude-sonnet-4-5",
      max_tokens=1000,
      messages=[
          {
              "role": "user",
              "content": "Hello, Claude!"
          }
      ]
  )

  print(message.content)
  ```
  </CodeGroup>

  <Warning>
  Replace `sk_shinzo_live_your_key_here` with your actual Shinzo API key.
  </Warning>
</Step>

<Step title="Verify the configuration">
  Run your agent and make a test request. Then check the [Shinzo Dashboard](https://app.shinzo.ai) to see your conversation appear.

  <Check>
  If you see your conversation in **Analytics > Agent Analytics**, you're all set!
  </Check>
</Step>
</Steps>

<Step title="Add custom spans (optional)">
  For even more detailed traces, add custom spans to your agent logic:

  <CodeGroup>
  ```typescript TypeScript
  import { trace } from "@opentelemetry/api";

  const tracer = trace.getTracer("my-agent");

  async function processUserRequest(userInput: string) {
    const span = tracer.startSpan("process_user_request");

    try {
      span.setAttribute("user_input_length", userInput.length);

      // Your agent logic here
      const message = await anthropic.messages.create({
        model: "claude-sonnet-4-5",
        max_tokens: 1000,
        messages: [{ role: "user", content: userInput }]
      });

      span.setAttribute("response_length", message.content[0].text.length);
      span.setStatus({ code: 1 }); // Success

      return message;
    } catch (error) {
      span.recordException(error);
      span.setStatus({ code: 2, message: error.message }); // Error
      throw error;
    } finally {
      span.end();
    }
  }
  ```

  ```python Python
  from opentelemetry import trace

  tracer = trace.get_tracer("my-agent")

  def process_user_request(user_input: str):
      with tracer.start_as_current_span("process_user_request") as span:
          span.set_attribute("user_input_length", len(user_input))

          # Your agent logic here
          message = client.messages.create(
              model="claude-sonnet-4-5",
              max_tokens=1000,
              messages=[{"role": "user", "content": user_input}]
          )

          span.set_attribute("response_length", len(message.content[0].text))

          return message
  ```
  </CodeGroup>
</Step>

## Building an Agent with Observability

Here's a complete example of building a simple agent with full observability:

<CodeGroup>
```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";
import { ShinzoTelemetry } from "@shinzolabs/telemetry-anthropic";

// Initialize telemetry
const telemetry = new ShinzoTelemetry({
  apiKey: process.env.SHINZO_API_KEY,
  serviceName: "customer-support-agent",
  environment: process.env.NODE_ENV || "development"
});

// Create instrumented Anthropic client
const anthropic = telemetry.instrumentAnthropic(new Anthropic({
  apiKey: process.env.SHINZO_API_KEY,
  baseURL: "https://api.app.shinzo.ai/spotlight/anthropic"
}));

// Define tools for the agent
const tools = [
  {
    name: "search_knowledge_base",
    description: "Search the knowledge base for answers to customer questions",
    input_schema: {
      type: "object",
      properties: {
        query: {
          type: "string",
          description: "The search query"
        }
      },
      required: ["query"]
    }
  }
];

// Agent conversation loop
async function runAgent(userMessage: string) {
  const messages = [
    {
      role: "user" as const,
      content: userMessage
    }
  ];

  let response = await anthropic.messages.create({
    model: "claude-sonnet-4-5",
    max_tokens: 2000,
    tools: tools,
    messages: messages
  });

  // Handle tool calls
  while (response.stop_reason === "tool_use") {
    const toolUse = response.content.find(
      block => block.type === "tool_use"
    );

    if (!toolUse || toolUse.type !== "tool_use") break;

    // Execute tool (searchKnowledgeBase is your implementation)
    const toolResult = await searchKnowledgeBase(toolUse.input.query);

    // Add assistant response and tool result to messages
    messages.push({
      role: "assistant",
      content: response.content
    });

    messages.push({
      role: "user",
      content: [
        {
          type: "tool_result",
          tool_use_id: toolUse.id,
          content: JSON.stringify(toolResult)
        }
      ]
    });

    // Continue conversation
    response = await anthropic.messages.create({
      model: "claude-sonnet-4-5",
      max_tokens: 2000,
      tools: tools,
      messages: messages
    });
  }

  return response;
}

// Example usage
const response = await runAgent("How do I reset my password?");
console.log(response.content[0].text);
```

```python Python
import anthropic
import os
from shinzo_telemetry import ShinzoTelemetry

# Initialize telemetry
telemetry = ShinzoTelemetry(
    api_key=os.environ["SHINZO_API_KEY"],
    service_name="customer-support-agent",
    environment=os.environ.get("ENV", "development")
)

# Create instrumented Anthropic client
client = telemetry.instrument_anthropic(
    anthropic.Anthropic(
        api_key=os.environ["SHINZO_API_KEY"],
        base_url="https://api.app.shinzo.ai/spotlight/anthropic"
    )
)

# Define tools for the agent
tools = [
    {
        "name": "search_knowledge_base",
        "description": "Search the knowledge base for answers to customer questions",
        "input_schema": {
            "type": "object",
            "properties": {
                "query": {
                    "type": "string",
                    "description": "The search query"
                }
            },
            "required": ["query"]
        }
    }
]

# Agent conversation loop
def run_agent(user_message: str):
    messages = [
        {
            "role": "user",
            "content": user_message
        }
    ]

    response = client.messages.create(
        model="claude-sonnet-4-5",
        max_tokens=2000,
        tools=tools,
        messages=messages
    )

    # Handle tool calls
    while response.stop_reason == "tool_use":
        tool_use = next(
            (block for block in response.content if block.type == "tool_use"),
            None
        )

        if not tool_use:
            break

        # Execute tool (search_knowledge_base is your implementation)
        tool_result = search_knowledge_base(tool_use.input["query"])

        # Add assistant response and tool result to messages
        messages.append({
            "role": "assistant",
            "content": response.content
        })

        messages.append({
            "role": "user",
            "content": [
                {
                    "type": "tool_result",
                    "tool_use_id": tool_use.id,
                    "content": str(tool_result)
                }
            ]
        })

        # Continue conversation
        response = client.messages.create(
            model="claude-sonnet-4-5",
            max_tokens=2000,
            tools=tools,
            messages=messages
        )

    return response

# Example usage
response = run_agent("How do I reset my password?")
print(response.content[0].text)
```

## What Data is Collected?

When you instrument your Anthropic SDK agents with Shinzo, the following data is automatically captured:

### Conversation Data
- User messages and agent responses
- Full conversation context and history
- Model configuration (model, temperature, max_tokens, etc.)
- Timestamps and latency for each message

### Tool Usage
- Tool definitions and schemas
- Tool invocations with parameters
- Tool results and outputs
- Tool execution time and success rate

### Performance Metrics
- **Response time**: Time from prompt to response
- **Token counts**: Input and output tokens per message
- **Costs**: Estimated cost based on model pricing
- **Throughput**: Messages per second, tokens per second
- **Cache hits**: Prompt caching utilization

### Error Tracking
- Exception traces with stack traces
- Error messages and error types
- Failed tool calls
- Rate limit and quota errors

## Configuration Options

### Telemetry Sampling

Reduce telemetry volume by configuring sampling:

<CodeGroup>
```typescript TypeScript
const telemetry = new ShinzoTelemetry({
  apiKey: "sk_shinzo_live_your_key_here",
  sampling: {
    rate: 1.0  // Capture 100% of traces (default)
  }
});
```

```python Python
telemetry = ShinzoTelemetry(
    api_key="sk_shinzo_live_your_key_here",
    sampling_rate=1.0  # Capture 100% of traces (default)
)
```
</CodeGroup>

**Sampling rates**:
- `1.0`: Capture all traces (recommended for development)
- `0.5`: Capture 50% of traces
- `0.1`: Capture 10% of traces (for high-volume production)

### Custom Attributes

Add custom attributes to all traces:

<CodeGroup>
```typescript TypeScript
const telemetry = new ShinzoTelemetry({
  apiKey: "sk_shinzo_live_your_key_here",
  attributes: {
    environment: "production",
    version: "1.0.0",
    team: "customer-support"
  }
});
```

```python Python
telemetry = ShinzoTelemetry(
    api_key="sk_shinzo_live_your_key_here",
    attributes={
        "environment": "production",
        "version": "1.0.0",
        "team": "customer-support"
    }
)
```
</CodeGroup>

These attributes appear in the Shinzo dashboard and can be used for filtering.

## Troubleshooting

<AccordionGroup>
<Accordion title="Conversations not appearing in dashboard">
1. **Verify configuration**:
   - Check that `baseURL` is set to `https://api.app.shinzo.ai/spotlight/anthropic`
   - Verify your Shinzo API key is valid
   - Ensure your Anthropic key is stored in Shinzo (**Settings > API Keys > Provider Keys**)

2. **Test connectivity**:
   ```bash
   curl -I https://api.app.shinzo.ai/health
   ```

3. **Check for errors**: Enable debug logging to see detailed error messages:

   <CodeGroup>
   ```typescript TypeScript
   const telemetry = new ShinzoTelemetry({
     apiKey: "sk_shinzo_live_your_key_here",
     debug: true
   });
   ```

   ```python Python
   telemetry = ShinzoTelemetry(
       api_key="sk_shinzo_live_your_key_here",
       debug=True
   )
   ```
   </CodeGroup>
</Accordion>

<Accordion title="Authentication errors">
- **401 Unauthorized**: Your Shinzo API key is invalid or revoked
- **403 Forbidden - Subscription not supported**: You're using a Claude subscription OAuth token. Use an API key from the [Anthropic Console](https://console.anthropic.com/settings/keys).
- **403 Forbidden - Invalid provider key**: Your Anthropic key stored in Shinzo is invalid. Update it in **Settings > API Keys > Provider Keys**.
</Accordion>

<Accordion title="Missing tool usage data">
If you see conversations but not tool traces:

1. Ensure you're using Shinzo's telemetry SDK (Option 2 in setup)
2. Verify tools are actually being invoked in your agent
3. Check that tool results are being added to the conversation properly

Tool telemetry is automatically captured when using the instrumented client.
</Accordion>

<Accordion title="Performance overhead">
Shinzo's telemetry adds minimal overhead:

- **API proxying only**: ~10-30ms per request
- **Full telemetry SDK**: ~20-50ms per request

If you experience significant slowdowns:

1. Check network latency to `api.app.shinzo.ai`
2. Reduce telemetry sampling (see Configuration below)
3. Ensure you're not blocking on telemetry export (async by default)
</Accordion>
</AccordionGroup>
