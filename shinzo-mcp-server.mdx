# Shinzo MCP Server

<Info>
**Alpha Testing in Progress**

The Shinzo MCP Server is currently in alpha testing with select early access partners. This MCP server enables AI agents to interact directly with the Shinzo Platform.
</Info>

## What is Shinzo MCP Server?

The Shinzo MCP Server is an official Model Context Protocol server that provides AI agents with direct access to Shinzo Platform capabilities. Through MCP, your agents can:

- **Query analytics data**: Access conversation history, token usage, and performance metrics
- **Manage resources**: Create and configure agents, MCP servers, and API keys
- **Monitor performance**: Retrieve real-time telemetry and observability data
- **Automate workflows**: Trigger actions based on analytics insights

## Why Use Shinzo MCP Server?

### Agent-Native Platform Access

Instead of requiring developers to manually check dashboards or write custom API integrations, the Shinzo MCP Server gives your AI agents direct access to platform capabilities. This enables:

- **Self-monitoring agents**: Agents that can query their own performance metrics
- **Autonomous optimization**: Agents that adjust their behavior based on analytics
- **Multi-agent coordination**: Agents that can discover and communicate with other agents
- **Intelligent resource management**: Agents that can create and configure their own resources

### Built on MCP Standards

As an official MCP server, Shinzo integrates seamlessly with:

- **Claude Code**: Use Shinzo MCP Server directly from Claude CLI
- **Custom agents**: Integrate via the MCP SDKs (TypeScript, Python)
- **Third-party tools**: Any MCP-compatible client can connect

## Example Use Cases

### Self-Monitoring Agent
```typescript
// Agent queries its own conversation analytics
const myConversations = await mcpClient.useTool("shinzo", "get-agent-analytics", {
  agentId: "agent-abc123",
  timeRange: "last-24h"
});

// Adjust behavior based on token usage
if (myConversations.totalTokens > 100000) {
  // Switch to more concise responses
}
```

### Multi-Agent Orchestration
```python
# Discover available agents
agents = await mcp_client.call_tool("shinzo", "list-agents")

# Route request to specialized agent
support_agent = next(a for a in agents if a["type"] == "customer-support")
response = await mcp_client.call_tool("shinzo", "send-agent-message", {
    "agentId": support_agent["id"],
    "message": "Help with billing question"
})
```

### Analytics-Driven Workflow
```typescript
// Query for high-error conversations
const errorConversations = await mcpClient.useTool("shinzo", "search-conversations", {
  filters: {
    errorRate: { greaterThan: 0.1 },
    timeRange: "last-hour"
  }
});

// Alert team if threshold exceeded
if (errorConversations.length > 10) {
  await notifyTeam("High error rate detected");
}
```

## Available Tools

The Shinzo MCP Server will provide these tools (subject to change during alpha):

### Agent Management
- `list-agents`: List all agents in your workspace
- `get-agent`: Get details about a specific agent
- `create-agent`: Deploy a new agent
- `update-agent`: Modify agent configuration
- `delete-agent`: Remove an agent

### Analytics & Monitoring
- `get-agent-analytics`: Retrieve conversation analytics for an agent
- `search-conversations`: Search conversation history with filters
- `get-token-usage`: Query token consumption and costs
- `get-performance-metrics`: Retrieve latency and throughput data

### MCP Server Management
- `list-mcp-servers`: List configured MCP servers
- `get-mcp-server-stats`: Get usage statistics for MCP servers
- `create-mcp-server`: Configure a new MCP server

### Platform Resources
- `list-api-keys`: List API keys in your workspace
- `create-api-key`: Generate a new API key
- `revoke-api-key`: Revoke an existing key
