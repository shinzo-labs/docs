---
title: "Revoke Token"
api: "DELETE https://api.app.shinzo.ai/v1/tokens/{token_id}"
description: "Revoke an existing token"
---

Permanently revoke an authentication token. Revoked tokens can no longer be used for authentication.

<ParamField path="token_id" type="string" required>
  The token identifier to revoke
</ParamField>

<ResponseField name="success" type="boolean">
  Indicates if the request was successful
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      The revoked token identifier
    </ResponseField>
    <ResponseField name="revoked_at" type="string">
      Revocation timestamp
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE https://api.app.shinzo.ai/v1/tokens/tok_ghi789 \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

```python Python
import requests

response = requests.delete(
    "https://api.app.shinzo.ai/v1/tokens/tok_ghi789",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"}
)
print(response.json())
```

```typescript TypeScript
const response = await fetch(
  "https://api.app.shinzo.ai/v1/tokens/tok_ghi789",

  }

const data = await response.json();
```
