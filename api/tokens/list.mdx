---
title: "List Tokens"
api: "GET https://api.app.shinzo.ai/v1/tokens"
description: "Retrieve all tokens for your account"
---

List all authentication tokens associated with your account. Token values are masked for security.

<ResponseField name="success" type="boolean">
  Indicates if the request was successful
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="tokens" type="array">
      Array of token objects (values masked)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET https://api.app.shinzo.ai/v1/tokens \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

```python Python
import requests

response = requests.get(
    "https://api.app.shinzo.ai/v1/tokens",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"}
)
print(response.json())
```

```typescript TypeScript
const response = await fetch(
  "https://api.app.shinzo.ai/v1/tokens",
  {
    headers: { Authorization: "Bearer YOUR_API_TOKEN" }
  }
);
const data = await response.json();
```
</RequestExample>
