---
title: "View Shared Session"
description: "View a shared session using the share token. This endpoint is public."
api: "GET /spotlight/analytics/sessions/shared/{shareToken}"
---

## Authentication

None required.

## Path Parameters

<ParamField path="shareToken" type="string" required>The share token from the share URL</ParamField>

## Example Request

```bash
curl -X GET https://api.app.shinzo.ai/spotlight/analytics/sessions/shared/shr_xyz789abc123
```

```json
    {
      "timestamp": "2025-01-15T10:00:00Z",
      "model": "claude-sonnet-4-20250514",

```

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Success |
| `404` | Share token not found or expired |
