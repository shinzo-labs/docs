---
title: "Get Session Details"
description: "Get detailed information about a specific session including all interactions."
api: "GET /spotlight/analytics/sessions/{sessionUuid}"
---

## Authentication

Requires JWT token authentication.

## Path Parameters

<ParamField path="sessionUuid" type="string" required>The session UUID</ParamField>

## Example Request

```bash
curl -X GET https://api.app.shinzo.ai/spotlight/analytics/sessions/sess_abc123 \
  -H "Authorization: Bearer <jwt_token>"
```

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Success |
| `401` | Unauthorized - invalid or missing JWT token |
| `404` | Session not found |
