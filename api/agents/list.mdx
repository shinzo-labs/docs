---
title: "List Agents"
description: "Retrieve a list of all your AI agents."
api: "GET /v1/agent/list"
---

## Authentication

Requires JWT token or Platform API key via `Authorization: Bearer <token>` header.

## Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `page` | number | `1` | Page number (min: 1) |
| `limit` | number | `20` | Results per page (1-100) |
| `status` | string | - | Filter by status: `active`, `paused`, `stopped`, or `error` |
| `sort` | string | `created_at` | Sort field: `created_at`, `updated_at`, or `name` |
| `order` | string | `desc` | Sort order: `asc` or `desc` |

## Example Request

```bash
curl -X GET "https://api.app.shinzo.ai/v1/agent/list?limit=10&status=active" \
  -H "Authorization: Bearer <token>"
```

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Success |
| `401` | Unauthorized - invalid or missing authentication |
| `403` | AI Agents feature not enabled for your account |
