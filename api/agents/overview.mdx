The Shinzo Platform allows you to deploy and manage autonomous AI agents that can execute complex tasks. Agents run in isolated Kubernetes environments with persistent storage and can interact with external services via MCP servers.

## Features

- **Isolated Environments**: Each agent runs in its own container with dedicated resources and persistent storage
- **Messaging**: Send messages to agents and receive responses via the API or connected channels
- **Channel Integrations**: Connect agents to Discord, with Slack, Telegram, and WhatsApp coming soon
- **Filesystem API**: Read, write, and manage files in the agent's workspace
- **MCP Support**: Connect agents to MCP servers for external service integration
- **Webhooks**: Receive notifications when messages complete, fail, or when errors occur

## Authentication

All agent endpoints accept either:

- **JWT Token**: `Authorization: Bearer <jwt_token>`
- **Platform API Key**: `Authorization: Bearer <api_key>`

## Feature Flag

AI Agents must be enabled for your account. If you receive a `403 Forbidden` error, contact support to enable this feature.

## Endpoints

### Agent Lifecycle

| Endpoint | Method | Description |
|----------|--------|-------------|
| [`/v1/agent/create`](/api/agents/create) | POST | Deploy a new AI agent |
| [`/v1/agent/list`](/api/agents/list) | GET | List all your agents |
| [`/v1/agent/{id}`](/api/agents/get) | GET | Get agent details |
| [`/v1/agent/update/{id}`](/api/agents/update) | POST | Update agent configuration |
| [`/v1/agent/delete/{id}`](/api/agents/delete) | POST | Delete an agent |
| [`/v1/agent/{id}/pause`](/api/agents/pause) | POST | Pause an agent |
| [`/v1/agent/{id}/resume`](/api/agents/resume) | POST | Resume a paused agent |

### Messaging

| Endpoint | Method | Description |
|----------|--------|-------------|
| [`/v1/agent/{id}/messages`](/api/agents/send-message) | POST | Send a message to an agent |
| [`/v1/agent/{id}/messages`](/api/agents/list-messages) | GET | List messages for an agent |

### Channels

| Endpoint | Method | Description |
|----------|--------|-------------|
| [`/v1/agent/{id}/channels`](/api/agents/list-channels) | GET | List channel bindings |
| [`/v1/agent/{id}/discord/link`](/api/agents/discord-link) | POST | Generate a Discord link code |
| [`/v1/agent/{id}/discord/status`](/api/agents/discord-status) | GET | Check Discord link status |
| [`/v1/agent/{id}/discord/unlink`](/api/agents/discord-unlink) | DELETE | Unlink Discord from agent |

### Filesystem

| Endpoint | Method | Description |

| `/v1/agent/{id}/filesystem/files/{path}` | GET | Read file contents |
| `/v1/agent/{id}/filesystem/files/{path}` | POST | Create a new file |
| `/v1/agent/{id}/filesystem/files/{path}` | PUT | Update file contents |
| `/v1/agent/{id}/filesystem/files/{path}` | DELETE | Delete a file |
| `/v1/agent/{id}/filesystem/directories/{path}` | GET | List directory contents |
| `/v1/agent/{id}/filesystem/directories/{path}` | POST | Create a directory |
| `/v1/agent/{id}/filesystem/directories/{path}` | DELETE | Delete a directory |

| `/v1/agent/{id}/filesystem/metadata/{path}` | PATCH | Update file metadata |
| `/v1/agent/{id}/filesystem/operations/copy` | POST | Copy files or directories |
| `/v1/agent/{id}/filesystem/operations/move` | POST | Move or rename files |
| `/v1/agent/{id}/filesystem/operations/search` | POST | Search files by name or content |
| `/v1/agent/{id}/filesystem/archives` | POST | Create an archive |
| `/v1/agent/{id}/filesystem/archives/extract` | POST | Extract an archive |

## Agent States

| State | Description |
|-------|-------------|
| `active` | Agent is running and accepting messages |
| `paused` | Agent is paused and will not process new messages |
| `stopped` | Agent has been stopped |
| `error` | Agent encountered an error |
