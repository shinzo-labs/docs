---
title: "Extract Archive"
description: "Extract a compressed archive in an agent's workspace."
api: "POST /v1/agent/{agentId}/filesystem/archives/extract"
---

## Authentication

Requires JWT token or Platform API key.

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `agentId` | string | Yes | Agent UUID |

## Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `archive_path` | string | Yes | Path to the archive file in the workspace |
| `destination` | string | Yes | Directory to extract the archive contents into |
| `overwrite` | boolean | No | Overwrite existing files during extraction |

## Example Request

```bash
curl -X POST "https://api.app.shinzo.ai/v1/agent/agt_abc123/filesystem/archives/extract" \
  -H "Authorization: Bearer <jwt_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "archive_path": "/workspace/backup.tar.gz",
    "destination": "/workspace/restored",
    "overwrite": true
  }'
```

## Response

```json
{
  "destination": "/workspace/restored",
  "files_extracted": 12
}
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `destination` | string | Directory where the archive was extracted |
| `files_extracted` | number | Total number of files extracted |

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Archive extracted successfully |
| `400` | Invalid request body or unsupported archive format |
| `401` | Invalid authentication |
| `403` | Access denied |
| `404` | Agent or archive file not found |
