---
title: "List Messages"
description: "Retrieve messages for an agent with cursor-based pagination."
api: "GET /v1/agent/{id}/messages"
---

## Authentication

Requires JWT token or Platform API key via `Authorization: Bearer <token>` header.

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | string | Yes | Agent UUID |

## Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `limit` | number | `50` | Results per page (1-100) |
| `before` | string | - | UUID cursor -- return messages before this message ID |
| `after` | string | - | UUID cursor -- return messages after this message ID |
| `status` | string | - | Filter by status: `pending`, `delivered`, or `read` |
| `channel` | string | - | Filter by channel: `api`, `discord`, `slack`, or `whatsapp` |

## Example Request

```bash
curl -X GET "https://api.app.shinzo.ai/v1/agent/a1b2c3d4-e5f6-7890-abcd-ef1234567890/messages?limit=20&channel=api" \
  -H "Authorization: Bearer <token>"
```

## Pagination

This endpoint uses cursor-based pagination. To fetch the next page, pass the `id` of the last message in your current page as the `after` parameter. To fetch previous messages, pass the `id` of the first message as the `before` parameter.

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Success |
| `401` | Unauthorized - invalid or missing authentication |
| `404` | Agent not found |
