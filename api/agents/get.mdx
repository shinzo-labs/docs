# Get Agent

Get detailed information about a specific agent.

## Endpoint

```
GET /agent/:id
```

## Authentication

Requires JWT token or Platform API key.

## Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | string | Agent UUID |

## Example Request

```bash
curl -X GET https://api.app.shinzo.ai/agent/agt_abc123def456 \
  -H "Authorization: Bearer <jwt_token>"
```

## Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `uuid` | string | Unique agent identifier |
| `name` | string | Agent name |
| `description` | string | Agent description |
| `status` | string | Current status |
| `endpoint_url` | string | Agent's API endpoint |
| `container_id` | string | Kubernetes pod identifier |
| `configuration` | object | Agent configuration |
| `stats` | object | Usage statistics |

## Status Codes

| Code | Description |
|------|-------------|
| `200` | Success |
| `401` | Invalid authentication |
| `403` | AI Agents feature not enabled |
| `404` | Agent not found |
