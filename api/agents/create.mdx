---
title: "Create Agent"
description: "Deploy a new AI agent on the Shinzo Platform."
api: "POST /v1/agent/create"
---

## Authentication

Requires JWT token or Platform API key via `Authorization: Bearer <token>` header.

## Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Agent name (1-100 characters) |
| `description` | string | No | Agent description (max 500 characters) |
| `pvc_size` | string | No | Persistent volume size (default: `1Gi`) |
| `anthropic_api_key` | string | No | Anthropic API key for the agent. If omitted, your stored key is used |
| `system_prompt` | string | No | Custom system prompt for the agent |
| `system_prompt_type` | string | No | How to apply the system prompt: `replace` or `append` (default: `append`) |
| `configuration` | object | No | Agent configuration options (see below) |
| `initial_files` | array | No | Files to create in the agent workspace on deploy |

### Configuration Object

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `timeout_seconds` | number | `3600` | Task timeout in seconds |
| `model` | string | - | Model name to use |
| `mcp_servers` | object | - | MCP server configurations |
| `memory_config` | object | - | Memory configuration |
| `webhooks` | object | - | Webhook URLs for notifications |
| `compaction` | object | - | Context compaction configuration |
| `custom_env` | object | - | Custom environment variables injected into the agent container |

### Memory Configuration

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `type` | string | `hierarchical` | Memory type (`hierarchical` or `flat`) |
| `max_size_mb` | number | `1024` | Maximum memory size in MB |
| `persistence` | string | `persistent` | Memory persistence (`ephemeral` or `persistent`) |

### Webhooks

| Field | Type | Description |
|-------|------|-------------|
| `message_complete` | string | URL called when a message completes |
| `message_failed` | string | URL called when a message fails |
| `agent_error` | string | URL called on agent error |

### Compaction

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `enabled` | boolean | `true` | Enable context compaction |
| `model` | string | `claude-haiku-4-5-20251001` | Model used for summarization |
| `threshold_trigger` | number | `120000` | Input token threshold to trigger compaction |

### Initial Files

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `path` | string | Yes | File path in the agent workspace |
| `content` | string | Yes | File content |
| `encoding` | string | No | Content encoding: `utf-8` (default) or `base64` |

## Example Request

```bash
curl -X POST https://api.app.shinzo.ai/v1/agent/create \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "code-review-agent",
    "description": "Agent for automated code reviews",
    "pvc_size": "5Gi",
    "system_prompt": "You are a senior code reviewer. Be thorough and constructive.",
    "system_prompt_type": "append",
    "configuration": {
      "timeout_seconds": 1800,
      "webhooks": {
        "message_complete": "https://myapp.com/webhooks/complete"
      },
      "compaction": {
        "enabled": true,
        "threshold_trigger": 100000
      }
    },
    "initial_files": [
      {
        "path": "config.json",
        "content": "{\"review_style\": \"thorough\"}"
      }
    ]
  }'
```

## Status Codes

| Code | Description |
|------|-------------|
| `201` | Agent created successfully |
| `400` | Invalid request (validation error) |
| `401` | Unauthorized - invalid or missing authentication |
| `403` | AI Agents feature not enabled for your account |
