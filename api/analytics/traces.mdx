---
title: "Query Traces"
api: "GET https://api.app.shinzo.ai/v1/analytics/traces"
description: "Search and retrieve traces with filtering and pagination"
---

Query traces with flexible filtering options. Use this endpoint to investigate specific tool executions, debug errors, or analyze performance patterns.

<ParamField query="server_id" type="string">
  Filter by server identifier
</ParamField>

<ParamField query="tool_name" type="string">
  Filter by tool name
</ParamField>

<ParamField query="session_id" type="string">
  Filter by session identifier
</ParamField>

<ParamField query="status" type="string">
  Filter by status: `success` or `error`
</ParamField>

<ParamField query="min_duration_ms" type="integer">
  Minimum duration filter (milliseconds)
</ParamField>

<ParamField query="max_duration_ms" type="integer">
  Maximum duration filter (milliseconds)
</ParamField>

<ParamField query="start_time" type="string">
  Start of time range (ISO 8601). Defaults to 24 hours ago.
</ParamField>

<ParamField query="end_time" type="string">
  End of time range (ISO 8601). Defaults to now.
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Results per page (max 200)
</ParamField>

<ParamField query="sort" type="string" default="timestamp">
  Sort field: `timestamp` or `duration`
</ParamField>

<ParamField query="order" type="string" default="desc">
  Sort order: `asc` or `desc`
</ParamField>

<ResponseField name="success" type="boolean">
  Indicates if the request was successful
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="traces" type="array">
      Array of trace objects
    </ResponseField>
    <ResponseField name="pagination" type="object">
      Pagination metadata
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.app.shinzo.ai/v1/analytics/traces?tool_name=get_weather&status=error&limit=10" \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

```python Python
import requests

response = requests.get(
    "https://api.app.shinzo.ai/v1/analytics/traces",
    params={
        "tool_name": "get_weather",
        "status": "error",
        "limit": 10
    },
    headers={"Authorization": "Bearer YOUR_API_TOKEN"}
)
print(response.json())
```
