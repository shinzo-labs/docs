---
title: "Update MCP Server"
description: "Update an existing MCP server's configuration."
api: "PUT /v1/mcp/servers/{id}"
---

## Authentication

Requires JWT token or Platform API key via `Authorization: Bearer <token>` header.

## Path Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | string | Yes | MCP server UUID |

## Request Body

All fields are optional. Only include the fields you want to update.

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Server name (1-100 characters) |
| `description` | string | Description (max 500 characters) |
| `command` | string | Command to run (stdio servers) |
| `args` | array | Command arguments (stdio servers) |
| `env` | object | Environment variables (stdio servers, stored encrypted) |
| `url` | string | Endpoint URL (HTTP servers) |
| `headers` | object | HTTP headers (HTTP servers, stored encrypted) |
| `status` | string | Server status: `active` or `inactive` |
| `configuration` | object | Additional configuration options |

## Example Request

```bash
curl -X PUT https://api.app.shinzo.ai/v1/mcp/servers/a1b2c3d4-e5f6-7890-abcd-ef1234567890 \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Updated GitHub MCP Server",
    "status": "inactive"
  }'
```

## Example Response

{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "name": "github-mcp",
  "description": "Updated GitHub MCP Server",

  "health_status": "healthy",
  "created_at": "2026-01-10T08:00:00Z",
  "updated_at": "2026-01-15T14:30:00Z"

## Status Codes

| Code | Description |
|------|-------------|
| `200` | MCP server updated successfully |
| `400` | Invalid request (validation error) |
| `401` | Unauthorized - invalid or missing authentication |
| `404` | MCP server not found |
| `409` | Server with that name already exists |
