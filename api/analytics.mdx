# Analytics API

The Analytics API provides programmatic access to traces, metrics, and aggregated analytics data. Use this API to build custom dashboards, integrate with alerting systems, or export data for analysis.

## Endpoints Overview

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/v1/analytics/overview` | Get analytics overview |
| `GET` | `/v1/analytics/traces` | Query traces |
| `GET` | `/v1/analytics/traces/{trace_id}` | Get trace details |
| `GET` | `/v1/analytics/metrics` | Query metrics |
| `GET` | `/v1/analytics/tools` | Get tool analytics |
| `GET` | `/v1/analytics/sessions` | Get session analytics |
| `POST` | `/v1/analytics/export` | Export analytics data |

## Analytics Overview

Get a high-level overview of your analytics data.

```
GET /v1/analytics/overview
```

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `server_id` | `string` | - | Filter by server (optional) |
| `start_time` | `datetime` | 24h ago | Start of time range (ISO 8601) |
| `end_time` | `datetime` | now | End of time range (ISO 8601) |

```bash
curl -X GET "https://api.app.shinzo.ai/v1/analytics/overview?start_time=2025-01-14T00:00:00Z" \
```

## Query Traces

Search and retrieve traces with filtering and pagination.

```
GET /v1/analytics/traces
```

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `server_id` | `string` | - | Filter by server |
| `tool_name` | `string` | - | Filter by tool name |
| `session_id` | `string` | - | Filter by session |
| `status` | `string` | - | Filter by status: `success`, `error` |
| `min_duration_ms` | `integer` | - | Minimum duration filter |
| `max_duration_ms` | `integer` | - | Maximum duration filter |
| `start_time` | `datetime` | 24h ago | Start of time range |
| `end_time` | `datetime` | now | End of time range |
| `page` | `integer` | `1` | Page number |
| `limit` | `integer` | `50` | Results per page (max 200) |
| `sort` | `string` | `timestamp` | Sort field: `timestamp`, `duration` |
| `order` | `string` | `desc` | Sort order: `asc`, `desc` |

### Example Request

```bash
curl -X GET "https://api.app.shinzo.ai/v1/analytics/traces?tool_name=get_weather&status=error&limit=10" \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

## Query Metrics

Retrieve time-series metrics for visualization and analysis.

```
GET /v1/analytics/metrics
```

### Query Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `metric` | `string` | required | Metric name (see below) |
| `server_id` | `string` | - | Filter by server |
| `tool_name` | `string` | - | Filter by tool |
| `start_time` | `datetime` | 24h ago | Start of time range |
| `end_time` | `datetime` | now | End of time range |
| `interval` | `string` | `auto` | Aggregation interval: `1m`, `5m`, `15m`, `1h`, `1d` |
| `aggregation` | `string` | `avg` | Aggregation function: `avg`, `sum`, `min`, `max`, `p50`, `p95`, `p99` |

### Available Metrics

| Metric | Description |
|--------|-------------|
| `invocations` | Number of tool invocations |
| `errors` | Number of errors |
| `error_rate` | Error rate (0.0 to 1.0) |
| `duration` | Response time in milliseconds |
| `throughput` | Requests per second |

### Example Request

```bash
curl -X GET "https://api.app.shinzo.ai/v1/analytics/metrics?metric=duration&aggregation=p95&interval=5m" \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

## Export Analytics Data

Export analytics data in various formats for external analysis.

```
POST /v1/analytics/export
```

### Request Body

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `type` | `string` | Yes | Export type: `traces`, `metrics`, `tools`, `sessions` |
| `format` | `string` | Yes | Output format: `json`, `csv`, `parquet` |
| `start_time` | `datetime` | Yes | Start of time range |
| `end_time` | `datetime` | Yes | End of time range |
| `server_id` | `string` | No | Filter by server |
| `filters` | `object` | No | Additional filters |

### Example Request

```bash
curl -X POST https://api.app.shinzo.ai/v1/analytics/export \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "traces",
    "format": "csv",
    "start_time": "2025-01-01T00:00:00Z",
    "end_time": "2025-01-15T00:00:00Z",
    "filters": {
      "status": "error"
    }
  }'
```

### Response

```json
{
  "success": true,
  "data": {
    "export_id": "exp_abc123",
    "status": "processing",
    "estimated_completion": "2025-01-15T17:05:00Z",
    "download_url": null
  }
}
```

## Error Responses

### Invalid Time Range

```json
{
  "success": false,
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Invalid time range: start_time must be before end_time"
  }
}
```

### Time Range Too Large

```json
{
  "success": false,
  "error": {
    "code": "INVALID_REQUEST",
    "message": "Time range exceeds maximum of 30 days for this endpoint"
  }
}
```

### Export Not Found

```json
{
  "success": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "Export 'exp_notfound' does not exist or has expired"
  }
}
```
