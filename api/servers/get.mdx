---
title: "Get Server Details"
api: "GET https://api.app.shinzo.ai/v1/servers/{server_id}"
description: "Retrieve detailed information about a specific server"
---

Get comprehensive details about a registered MCP server, including its configuration, registered tools, and performance statistics.

<ParamField path="server_id" type="string" required>
  The unique server identifier (e.g., `srv_abc123`)
</ParamField>

<ResponseField name="success" type="boolean">
  Indicates if the request was successful
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Unique server identifier
    </ResponseField>
    <ResponseField name="name" type="string">
      Server name
    </ResponseField>
    <ResponseField name="version" type="string">
      Server version
    </ResponseField>
    <ResponseField name="description" type="string">
      Server description
    </ResponseField>
    <ResponseField name="status" type="string">
      Server status: `active`, `inactive`, or `error`
    </ResponseField>
    <ResponseField name="environment" type="string">
      Deployment environment
    </ResponseField>
    <ResponseField name="created_at" type="string">
      Registration timestamp (ISO 8601)
    </ResponseField>
    <ResponseField name="last_seen_at" type="string">
      Last telemetry received (ISO 8601)
    </ResponseField>
    <ResponseField name="configuration" type="object">
      Server configuration settings
    </ResponseField>
    <ResponseField name="tools" type="array">
      List of registered tools with usage statistics
    </ResponseField>
    <ResponseField name="stats" type="object">
      Aggregated performance statistics
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET https://api.app.shinzo.ai/v1/servers/srv_abc123 \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

```python Python
import requests

response = requests.get(

    headers={"Authorization": "Bearer YOUR_API_TOKEN"}
)
print(response.json())
```
