---
title: "Register Server"
api: "POST https://api.app.shinzo.ai/v1/servers"
description: "Register a new MCP server with the platform"
---

Register a new MCP server to start collecting telemetry data. An ingest token is automatically generated and returned with the response.

<Warning>
The ingest token is only displayed once during registration. Store it securely as it cannot be retrieved later.
</Warning>

<ParamField body="name" type="string" required>
  Server name (must be unique per account)
</ParamField>

<ParamField body="version" type="string" required>
  Server version (e.g., `1.0.0`)
</ParamField>

<ParamField body="description" type="string">
  Optional description of the server's purpose
</ParamField>

<ParamField body="environment" type="string" default="production">
  Deployment environment (e.g., `production`, `staging`, `development`)
</ParamField>

<ParamField body="configuration" type="object">
  Server configuration options
  <Expandable title="properties">
    <ParamField body="configuration.sampling_rate" type="number" default="1.0">
      Trace sampling rate (0.0 to 1.0)
    </ParamField>
    <ParamField body="configuration.pii_sanitization" type="boolean" default="true">
      Enable automatic PII sanitization
    </ParamField>
    <ParamField body="configuration.argument_collection" type="boolean" default="false">
      Collect tool arguments in traces
    </ParamField>
  </Expandable>
</ParamField>

<ResponseField name="success" type="boolean">
  Indicates if the request was successful
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      Unique server identifier
    </ResponseField>
    <ResponseField name="name" type="string">
      Server name
    </ResponseField>
    <ResponseField name="version" type="string">
      Server version
    </ResponseField>
    <ResponseField name="status" type="string">
      Server status (initially `inactive`)
    </ResponseField>
    <ResponseField name="ingest_token" type="object">
      <Expandable title="properties">
        <ResponseField name="id" type="string">
          Token identifier
        </ResponseField>
        <ResponseField name="token" type="string">
          The ingest token value (only shown once)
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://api.app.shinzo.ai/v1/servers \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "database-server",
    "version": "1.0.0",
    "description": "Database query MCP server",
    "environment": "production",
    "configuration": {
      "sampling_rate": 0.1,
      "pii_sanitization": true,
      "argument_collection": false
    }
  }'
```

```python Python
import requests

response = requests.post(
    "https://api.app.shinzo.ai/v1/servers",
    headers={

        "Content-Type": "application/json"
    },
    json={

        "version": "1.0.0",
        "description": "Database query MCP server",
        "environment": "production",
        "configuration": {
            "sampling_rate": 0.1,
            "pii_sanitization": True,
            "argument_collection": False
        }
    }
)
print(response.json())
```
