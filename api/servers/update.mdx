---
title: "Update Server"
api: "PATCH https://api.app.shinzo.ai/v1/servers/{server_id}"
description: "Update a server's configuration or metadata"
---

Update a registered MCP server's configuration, version, or metadata. Only the fields you include in the request body will be updated.

<ParamField path="server_id" type="string" required>
  The unique server identifier (e.g., `srv_abc123`)
</ParamField>

<ParamField body="version" type="string">
  Updated server version
</ParamField>

<ParamField body="description" type="string">
  Updated server description
</ParamField>

<ParamField body="environment" type="string">
  Updated deployment environment
</ParamField>

<ParamField body="configuration" type="object">
  Configuration updates (merged with existing configuration)
  <Expandable title="properties">
    <ParamField body="configuration.sampling_rate" type="number">
      Trace sampling rate (0.0 to 1.0)
    </ParamField>
    <ParamField body="configuration.pii_sanitization" type="boolean">
      Enable automatic PII sanitization
    </ParamField>
    <ParamField body="configuration.argument_collection" type="boolean">
      Collect tool arguments in traces
    </ParamField>
    <ParamField body="configuration.alert_threshold_error_rate" type="number">
      Error rate threshold for alerts (0.0 to 1.0)
    </ParamField>
    <ParamField body="configuration.alert_threshold_latency_ms" type="integer">
      Latency threshold for alerts (in milliseconds)
    </ParamField>
  </Expandable>
</ParamField>

<ResponseField name="success" type="boolean">
  Indicates if the request was successful
</ResponseField>

<ResponseField name="data" type="object">
  The updated server object
</ResponseField>

<RequestExample>
```bash cURL
curl -X PATCH https://api.app.shinzo.ai/v1/servers/srv_abc123 \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "version": "1.1.0",
    "configuration": {
      "sampling_rate": 0.05
    }
  }'
```

```python Python
import requests

response = requests.patch(
    "https://api.app.shinzo.ai/v1/servers/srv_abc123",
    headers={
        "Authorization": "Bearer YOUR_API_TOKEN",
        "Content-Type": "application/json"
    },
    json={
        "version": "1.1.0",
        "configuration": {
            "sampling_rate": 0.05
        }
    }
)
print(response.json())
```
