---
title: "Delete Server"
api: "DELETE https://api.app.shinzo.ai/v1/servers/{server_id}"
description: "Remove a server registration permanently"
---

Permanently delete a registered MCP server and all associated data.

<Warning>
This action is irreversible. Deleting a server removes all associated telemetry data, analytics history, and configuration. Consider exporting your data before deletion.
</Warning>

<ParamField path="server_id" type="string" required>
  The unique server identifier (e.g., `srv_abc123`)
</ParamField>

<ResponseField name="success" type="boolean">
  Indicates if the request was successful
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="properties">
    <ResponseField name="id" type="string">
      The deleted server's identifier
    </ResponseField>
    <ResponseField name="deleted_at" type="string">
      Deletion timestamp (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X DELETE https://api.app.shinzo.ai/v1/servers/srv_abc123 \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

```python Python
import requests

response = requests.delete(
    "https://api.app.shinzo.ai/v1/servers/srv_abc123",
    headers={"Authorization": "Bearer YOUR_API_TOKEN"}
)
print(response.json())
```

