# Dashboard

The Shinzo Platform dashboard provides real-time visibility into your MCP server's performance, health, and usage patterns. This comprehensive interface helps you monitor, debug, and optimize your MCP infrastructure.

## Overview

The dashboard is your central hub for observability data, featuring:
- **Real-time metrics** showing current server performance
- **Interactive charts** with customizable time ranges
- **Alert indicators** for issues requiring attention
- **Navigation** to detailed views for traces, resources, and configuration

## Key Metrics

### Server Health
Monitor the overall health and availability of your MCP servers:
- **Uptime percentage**: Current availability status
- **Request success rate**: Percentage of successful tool executions
- **Error rate**: Failed requests over time
- **Average response time**: Performance indicators

### Traffic Patterns
Understand how your MCP server is being used:
- **Requests per minute**: Current load and traffic patterns
- **Tool usage distribution**: Which tools are called most frequently
- **Peak usage times**: When your server experiences high load
- **Geographic distribution**: Where requests are coming from (if available)

### Performance Metrics
Track your server's performance characteristics:
- **P50/P95/P99 response times**: Latency percentiles
- **Throughput**: Requests processed per second
- **Resource utilization**: Memory, CPU, and other server resources
- **Queue depth**: Pending requests waiting for processing

## Time Range Controls

Customize the dashboard view with flexible time range options:
- **Last hour**: Recent activity and current performance
- **Last 24 hours**: Daily patterns and trends
- **Last 7 days**: Weekly usage patterns
- **Last 30 days**: Monthly trends and growth
- **Custom range**: Specific time periods for detailed analysis

Use the time picker in the top-right corner to adjust the view timeframe.

## Filtering and Search

### Server Filtering
When monitoring multiple MCP servers:
- Filter by server name or version
- View specific environments (dev, staging, prod)
- Focus on servers with issues
- Compare performance across servers

### Metric Filtering
Customize which metrics are displayed:
- Hide/show specific metric categories
- Focus on performance vs. usage metrics
- Filter by tool names or types
- Show only errors or successful operations

## Alerts and Notifications

### Visual Indicators
The dashboard uses color coding and icons to highlight:
- 🟢 **Green**: Healthy servers and normal operation
- 🟡 **Yellow**: Warning conditions requiring attention
- 🔴 **Red**: Critical issues needing immediate action
- 🔵 **Blue**: Information and status updates

### Alert Types
Common alerts you might see:
- High error rates
- Slow response times
- Server unavailability
- Unusual traffic patterns
- Configuration issues

## Tips for Effective Monitoring

### Best Practices
1. **Set up alerts** for critical metrics like error rate and response time
2. **Monitor trends** rather than just current values
3. **Use multiple time ranges** to understand both immediate and long-term patterns
4. **Filter by server** when managing multiple MCP servers
5. **Save custom views** for different monitoring scenarios

### Common Patterns to Watch
- Sudden spikes in error rates
- Gradual increases in response time
- Unusual tool usage patterns
- Resource exhaustion indicators
- Traffic pattern changes

The dashboard is your window into MCP server health and performance. Use it regularly to stay informed about your infrastructure and quickly identify areas needing attention.
