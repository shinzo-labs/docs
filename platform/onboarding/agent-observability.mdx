# Agent Observability Onboarding

Welcome to Shinzo Platform! This guide will help you set up observability for your AI agents, whether you're using Claude Code or building custom agents with the Anthropic SDK.

## What You'll Get

By connecting your AI agents to Shinzo, you'll gain visibility into:

- **Conversation Traces**: See the full history of agent interactions and decisions
- **Token Usage & Costs**: Track token consumption and associated costs across all agent conversations
- **Tool & MCP Server Usage**: Monitor which tools and MCP servers your agents use most
- **Performance Metrics**: Track response times, success rates, and error patterns
- **Session Management**: Organize and analyze agent conversations by session
- **User Behavior**: Understand how users interact with your AI agents

## Prerequisites

Before you begin, ensure you have:

1. **A Shinzo Platform account** - [Sign up for free](https://app.shinzo.ai)
2. **An Anthropic API key** - Get one from the [Anthropic Console](https://console.anthropic.com/settings/keys)
3. **Your agent framework**:
   - [Claude Code](https://github.com/anthropics/claude-code) for CLI-based agents
   - [Anthropic SDK](https://github.com/anthropics/anthropic-sdk-typescript) or [Python SDK](https://github.com/anthropics/anthropic-sdk-python) for custom agents

## What Data is Collected?

Shinzo collects observability data to help you understand and improve your AI agents:

### Conversation Data
- User prompts and agent responses
- Tool calls and results
- Token counts (input/output)
- Model used and configuration
- Timestamps and latency

### Tool & MCP Usage
- Which tools/MCP servers are invoked
- Tool execution time and success rate
- Tool parameters and results
- Error messages and stack traces

### Performance Metrics
- Response time per message
- Token throughput
- Error rates
- Cache hit rates

<Warning>
**Privacy Note**: All telemetry data is encrypted in transit and at rest. You control your data retention policies in Settings. We never train models on your data.
</Warning>

## Current Limitations

<Warning>
**Early Access Notice**: Agent observability is currently in early access and has some limitations.

### Subscription-Based Support

Due to current platform architecture, agent observability has limitations with subscription-based Anthropic accounts (Claude Pro/Team with OAuth tokens).

**For best results:**
- Use API key-based Anthropic authentication from the [Anthropic Console](https://console.anthropic.com/settings/keys)
- Ensure your Anthropic API key is added to Shinzo (**Settings > API Keys > Provider Keys**)
- Contact [austin@shinzolabs.com](mailto:austin@shinzolabs.com) for early access to agent deployment features

### Coming Soon

We're actively working on:
- Full support for subscription-based Claude Code accounts
- Enhanced agent conversation analytics
- Agent performance benchmarking
- Multi-agent orchestration observability
- Custom dashboard widgets for agent metrics
</Warning>
