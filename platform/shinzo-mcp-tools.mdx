## Overview

The Shinzo MCP Server provides a comprehensive set of tools that enable your AI agents to interact with the Shinzo platform. Tools are organized into functional categories for easy discovery and use.

<Info>
**Using these tools:** Your AI agent automatically discovers and invokes these tools based on natural language requests. You don't need to call them manually—just describe what you want to do in conversation.
</Info>

## Agent Management Tools

### `shinzo_create_agent`

Create a new AI agent with specified configuration.

**Input Schema:**

```typescript
{
  name: string;              // Agent display name (required)
  model: string;             // AI model (e.g., "claude-3-7-sonnet-20250219", required)
  systemPrompt?: string;     // System prompt/instructions
  mcpServers?: Array<{       // MCP servers to configure
    name: string;
    type: 'github' | 'filesystem' | 'postgres' | 'slack' | 'custom';
    config: object;          // Server-specific configuration
  }>;
  initialFiles?: Array<{     // Files to initialize in agent workspace
    path: string;
    content: string;
  }>;
  resourceLimits?: {         // Optional resource constraints
    maxTokensPerMonth?: number;
    maxCostPerMonth?: number;  // in dollars
    maxStorageMB?: number;
  };
}
```

**Example Usage:**

```
"Create a new agent named 'docs-writer' using Claude 3.7 Sonnet.
Configure it with access to my GitHub repos and give it instructions
to help write technical documentation."
```

**Example Response:**

```json
{
  "agentId": "agent_abc123",
  "name": "docs-writer",
  "status": "active",
  "createdAt": "2026-02-17T20:00:00Z",
  "url": "https://app.shinzo.ai/agents/agent_abc123"
}
```

## MCP Configuration Tools

### `shinzo_add_mcp_server`

Add an MCP server to an agent's configuration.

**Input Schema:**

```typescript
{
  agentId: string;           // Agent ID (required)
  serverName: string;        // Server name (required)
  serverType: 'github' | 'filesystem' | 'postgres' | 'slack' | 'custom';
  config: object;            // Server-specific configuration
}
```

**Server Type Configs:**

<Tabs>
  <Tab title="GitHub">
    ```typescript
    {
      serverType: 'github',
      config: {
        repos: ['owner/repo'],      // Repositories to access
        token: 'ghp_xxxx'            // GitHub personal access token
      }
    }
    ```
  </Tab>

  <Tab title="Filesystem">
    ```typescript
    {
      serverType: 'filesystem',
      config: {
        allowedPaths: ['/path/to/dir']  // Paths the agent can access
      }
    }
    ```
  </Tab>

  <Tab title="PostgreSQL">
    ```typescript
    {
      serverType: 'postgres',
      config: {
        connectionString: 'postgresql://...'
      }
    }
    ```
  </Tab>

  <Tab title="Slack">
    ```typescript
    {
      serverType: 'slack',
      config: {
        botToken: 'xoxb-...',
        teamId: 'T1234567'
      }
    }
    ```
  </Tab>

  <Tab title="Custom">
    ```typescript
    {
      serverType: 'custom',
      config: {
        url: 'https://my-mcp-server.com/v1/mcp',
        headers: {
          'Authorization': 'Bearer token'
        }
      }
    }
    ```
  </Tab>
</Tabs>

**Example Usage:**

```
"Add the GitHub MCP server to agent_abc123 with access to shinzo-labs/docs"
```

**Example Response:**

```json
{
  "agentId": "agent_abc123",
  "serverName": "github",
  "added": true,
  "message": "GitHub MCP server added successfully"
}
```

## Error Handling

All tools follow a consistent error response format:

```json
{
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "Agent not found: agent_abc123",
    "details": {
      "agentId": "agent_abc123"
    }
  }
}
```

**Common Error Codes:**

| Code | Description | Resolution |
|------|-------------|------------|
| `AUTHENTICATION_FAILED` | Invalid or expired API key | Check your API key configuration |
| `RATE_LIMIT_EXCEEDED` | Too many requests | Wait and retry with exponential backoff |
| `RESOURCE_NOT_FOUND` | Agent/task/server not found | Verify the ID is correct |
| `VALIDATION_ERROR` | Invalid input parameters | Check the input schema |
| `QUOTA_EXCEEDED` | Monthly quota limit reached | Upgrade plan or wait for reset |
| `PERMISSION_DENIED` | Insufficient permissions | Check API key scopes |
| `SERVER_ERROR` | Internal server error | Retry or contact support |

## Rate Limits

| Plan | Requests/Minute | Burst Allowance |
|------|----------------|-----------------|
| Free | 100 | 120 |
| Pro | 500 | 600 |
| Team | 1000 | 1200 |
| Enterprise | Custom | Custom |

<Info>
**Handling rate limits:** Implement exponential backoff when receiving `429 Too Many Requests` responses. Start with a 1-second delay and double it with each retry, up to a maximum of 60 seconds.
</Info>
