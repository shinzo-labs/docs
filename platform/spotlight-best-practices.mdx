# Spotlight Best Practices

This guide covers advanced patterns, optimization strategies, and production best practices for using Spotlight effectively in your AI applications.

## Architecture Patterns

### Single Client Instance

Create one Anthropic client instance and reuse it throughout your application to improve performance and connection pooling.

<CodeGroup>
```typescript TypeScript
// ✅ Good: Single client instance
import Anthropic from "@anthropic-ai/sdk";

const anthropic = new Anthropic({
  apiKey: process.env.SHINZO_API_KEY,
  baseURL: "https://api.app.shinzo.ai/spotlight/anthropic"
});

export default anthropic;

// Use in other files
import anthropic from "./anthropic-client";

async function chat(message: string) {
  return await anthropic.messages.create({
    model: "claude-sonnet-4-20250514",
    max_tokens: 1000,
    messages: [{ role: "user", content: message }]
  });
}
```

### Service Layer Pattern

Encapsulate Spotlight configuration in a service layer for better maintainability and testing.

<CodeGroup>
```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";

class AIService {
  private client: Anthropic;
  private defaultModel: string;

  constructor(config?: { model?: string }) {
    this.client = new Anthropic({
      apiKey: process.env.SHINZO_API_KEY,
      baseURL: "https://api.app.shinzo.ai/spotlight/anthropic"
    });
    this.defaultModel = config?.model || "claude-sonnet-4-20250514";
  }

  async chat(
    userId: string,
    message: string,
    options?: {
      model?: string;
      maxTokens?: number;
      sessionId?: string;
    }
  ) {
    const sessionId = options?.sessionId || `user-${userId}`;

    return await this.client.messages.create({
      model: options?.model || this.defaultModel,
      max_tokens: options?.maxTokens || 1000,
      messages: [{ role: "user", content: message }],
      metadata: { user_id: sessionId }
    });
  }

  async generateWithContext(
    userId: string,
    systemPrompt: string,
    userMessage: string,
    conversationHistory?: Array<{ role: string; content: string }>
  ) {
    const messages = [
      ...(conversationHistory || []),
      { role: "user", content: userMessage }
    ];

    return await this.client.messages.create({
      model: this.defaultModel,
      max_tokens: 2000,
      system: systemPrompt,
      messages,
      metadata: { user_id: `user-${userId}` }
    });
  }
}

// Export singleton instance
export const aiService = new AIService();
```

## Session Management

### Session Naming Convention

Use a consistent naming convention for session IDs across your application.

```typescript
// Define session ID format based on context
function buildSessionId(
  context: "user" | "tenant" | "feature",
  identifiers: Record<string, string>
): string {
  switch (context) {
    case "user":
      return `user-${identifiers.userId}`;
    case "tenant":
      return `tenant-${identifiers.tenantId}-user-${identifiers.userId}`;
    case "feature":
      return `feature-${identifiers.feature}-user-${identifiers.userId}`;
    default:
      return "default-session";
  }
}

// Examples
const userSession = buildSessionId("user", { userId: "123" });
// => "user-123"

const tenantSession = buildSessionId("tenant", {
  tenantId: "acme",
  userId: "123"
});
// => "tenant-acme-user-123"

const featureSession = buildSessionId("feature", {
  feature: "chat",
  userId: "123"
});
// => "feature-chat-user-123"
```

### Model Selection Strategy

Choose the right model for each task to optimize cost and performance.

| Model | Best For | Cost | Speed |
|-------|----------|------|-------|
| **Claude Haiku** | Simple tasks, classification, extraction | $ | ⚡⚡⚡ |
| **Claude Sonnet** | Complex reasoning, balanced performance | $$ | ⚡⚡ |
| **Claude Opus** | Highly complex tasks, research, analysis | $$$ | ⚡ |

### Token Estimation

Estimate token usage before making requests to manage costs proactively.

```typescript
// Use the token counting endpoint
async function estimateTokens(messages: Array<{ role: string; content: string }>) {
  const response = await fetch(
    "https://api.app.shinzo.ai/spotlight/anthropic/v1/messages/count_tokens",
    {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${process.env.SHINZO_API_KEY}`,
        "Content-Type": "application/json"
      },
      body: JSON.stringify({
        model: "claude-sonnet-4-20250514",
        messages
      })
    }
  );

  const data = await response.json();
  return {
    inputTokens: data.input_tokens,
    estimatedCost: calculateCost(data.input_tokens, "input")
  };
}

function calculateCost(tokens: number, type: "input" | "output"): number {
  // Claude Sonnet pricing (as of 2025)
  const pricePerMToken = type === "input" ? 3 : 15;  // USD per 1M tokens
  return (tokens / 1_000_000) * pricePerMToken;
}

// Usage
const estimate = await estimateTokens([
  { role: "user", content: "Summarize this long document..." }
]);
console.log(`Estimated cost: $${estimate.estimatedCost.toFixed(4)}`);
```

## Error Handling

### Comprehensive Error Handling

Implement robust error handling for production applications.

<CodeGroup>
```typescript TypeScript
import Anthropic from "@anthropic-ai/sdk";

async function safeAPICall<T>(
  fn: () => Promise<T>,
  retries = 3,
  backoff = 1000
): Promise<T> {
  let lastError: Error;

  for (let i = 0; i < retries; i++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error as Error;

      // Handle specific errors
      if (error instanceof Anthropic.APIError) {
        switch (error.status) {
          case 401:
            throw new Error("Invalid API key - check your Shinzo credentials");
          case 403:
            throw new Error("Provider key not found or invalid");
          case 429:
            // Rate limit - wait and retry
            console.log(`Rate limited. Retrying in ${backoff}ms...`);
            await new Promise(resolve => setTimeout(resolve, backoff));
            backoff *= 2;  // Exponential backoff
            continue;
          case 500:
          case 503:
            // Server error - retry
            if (i < retries - 1) {
              console.log(`Server error. Retrying in ${backoff}ms...`);
              await new Promise(resolve => setTimeout(resolve, backoff));
              backoff *= 2;
              continue;
            }
            break;
          default:
            throw error;
        }
      }

      // Network error - retry
      if (i < retries - 1) {
        await new Promise(resolve => setTimeout(resolve, backoff));
        backoff *= 2;
        continue;
      }
    }
  }

  throw lastError!;
}

// Usage
async function chat(userId: string, message: string) {
  return await safeAPICall(async () => {
    return await anthropic.messages.create({
      model: "claude-sonnet-4-20250514",
      max_tokens: 1000,
      messages: [{ role: "user", content: message }],
      metadata: { user_id: `user-${userId}` }
    });
  });
}
```

```python Python
async def safe_api_call(
    fn: Callable[[], T],
    retries: int = 3,
    backoff: float = 1.0
) -> T:
    last_error = None

    for i in range(retries):
        try:
            return await fn()
        except anthropic.APIError as error:
            last_error = error

            # Handle specific errors
            if error.status_code == 401:
                raise Exception("Invalid API key - check your Shinzo credentials")
            elif error.status_code == 403:
                raise Exception("Provider key not found or invalid")
            elif error.status_code == 429:
                # Rate limit - wait and retry
                print(f"Rate limited. Retrying in {backoff}s...")
                await asyncio.sleep(backoff)
                backoff *= 2
                continue
            elif error.status_code in [500, 503]:
                # Server error - retry
                if i < retries - 1:
                    print(f"Server error. Retrying in {backoff}s...")
                    await asyncio.sleep(backoff)
                    backoff *= 2
                    continue
            else:
                raise

        except Exception as error:
            last_error = error
            # Network error - retry
            if i < retries - 1:
                await asyncio.sleep(backoff)
                backoff *= 2
                continue

    raise last_error
```

### Graceful Degradation

Implement fallback strategies when Spotlight is unavailable.

<CodeGroup>
```typescript TypeScript
class ResilientAIService {
  private primaryClient: Anthropic;
  private fallbackClient?: Anthropic;

  constructor() {
    // Primary: Spotlight (with analytics)
    this.primaryClient = new Anthropic({
      apiKey: process.env.SHINZO_API_KEY,
      baseURL: "https://api.app.shinzo.ai/spotlight/anthropic"
    });

    // Fallback: Direct to Anthropic (no analytics)
    if (process.env.ANTHROPIC_API_KEY) {
      this.fallbackClient = new Anthropic({
        apiKey: process.env.ANTHROPIC_API_KEY
      });
    }
  }

  async chat(userId: string, message: string) {
    try {
      // Try Spotlight first
      return await this.primaryClient.messages.create({
        model: "claude-sonnet-4-20250514",
        max_tokens: 1000,
        messages: [{ role: "user", content: message }],
        metadata: { user_id: `user-${userId}` }
      });
    } catch (error) {
      console.error("Spotlight unavailable, using fallback", error);

      // Fall back to direct Anthropic
      if (this.fallbackClient) {
        return await this.fallbackClient.messages.create({
          model: "claude-sonnet-4-20250514",
          max_tokens: 1000,
          messages: [{ role: "user", content: message }]
        });
      }

      throw error;
    }
  }
}
```

### Concurrent Requests

Make multiple independent requests in parallel for better performance.

<CodeGroup>

```typescript TypeScript
// Process multiple user requests concurrently
async function processBatch(requests: Array<{ userId: string; message: string }>) {
  const promises = requests.map(req =>
```

### Streaming for Long Responses

```typescript TypeScript
async function streamChat(userId: string, message: string) {
  const stream = await anthropic.messages.create({
    model: "claude-sonnet-4-20250514",
    max_tokens: 2000,
    messages: [{ role: "user", content: message }],
    stream: true,
    metadata: { user_id: `user-${userId}` }
  });

  let fullResponse = "";

  for await (const chunk of stream) {
    if (chunk.type === "content_block_delta") {
      const text = chunk.delta.text;
      fullResponse += text;

      // Send incremental updates to client
      await sendToClient(userId, text);
    }
  }

  return fullResponse;
}
```

### API Key Management

## Monitoring and Alerts

### Cost Monitoring

Set up alerts for unexpected cost increases.

```typescript
// Fetch daily costs and compare to threshold
async function checkDailyCosts() {
  const today = new Date().toISOString().split("T")[0];

  const response = await fetch(
    `https://api.app.shinzo.ai/spotlight/analytics/tokens?start_date=${today}`,
    {
      headers: {
        Authorization: `Bearer ${process.env.SHINZO_API_KEY}`
      }
    }
  );

  const data = await response.json();
  const dailyCost = calculateTotalCost(data);

  const threshold = 100; // $100 per day
  if (dailyCost > threshold) {
    await sendAlert(`Daily cost exceeded threshold: $${dailyCost.toFixed(2)}`);
  }

  return dailyCost;
}

function calculateTotalCost(analytics: any): number {
  // Calculate cost based on token usage
  const inputCost = (analytics.total_input_tokens / 1_000_000) * 3;
  const outputCost = (analytics.total_output_tokens / 1_000_000) * 15;
  return inputCost + outputCost;
}
```

### Error Rate Monitoring

Track and alert on high error rates.

```typescript
// Monitor error rates using Spotlight analytics
async function monitorErrorRates() {
  const response = await fetch(
    "https://api.app.shinzo.ai/spotlight/analytics/sessions?limit=100",
    {
      headers: {
        Authorization: `Bearer ${process.env.SHINZO_API_KEY}`
      }
    }
  );

  const data = await response.json();
  const sessions = data.sessions;

  const totalRequests = sessions.reduce(
    (sum: number, s: any) => sum + s.total_requests,
    0
  );
  const failedRequests = sessions.reduce(
    (sum: number, s: any) => sum + (s.failed_requests || 0),
    0
  );

  const errorRate = (failedRequests / totalRequests) * 100;

  const threshold = 5; // 5% error rate threshold
  if (errorRate > threshold) {
    await sendAlert(`Error rate exceeded threshold: ${errorRate.toFixed(2)}%`);
  }

  return errorRate;
}
```

## Troubleshooting Checklist

<AccordionGroup>
<Accordion title="Authentication Failures">
  1. Verify API key format: `sk_shinzo_live_...` or `sk_shinzo_test_...`
  2. Check key hasn't been deleted or expired
  3. Ensure correct header: `Authorization: Bearer <key>`
  4. Verify account is active and in good standing
</Accordion>

<Accordion title="Provider Key Issues">
  1. Add provider key in **Settings > API Keys > Provider Keys**
  2. Test provider key using the dashboard test button
  3. Verify provider key has sufficient quota
  4. Check if using subscription token (not supported)
</Accordion>

<Accordion title="Missing Analytics">
  1. Wait 30-60 seconds for analytics to appear
  2. Verify `metadata.user_id` is included in requests
  3. Check correct date range filter in dashboard
  4. Use API to verify: `GET /spotlight/analytics/sessions`
</Accordion>

<Accordion title="Slow Requests">
  1. Check Spotlight Analytics for latency metrics
  2. Verify provider API status
  3. Use streaming for long responses
  4. Check network connectivity and routing
  5. Consider geographic proximity to API endpoints
</Accordion>

<Accordion title="High Costs">
  1. Review token usage in Spotlight Analytics
  2. Optimize prompts to reduce token consumption
  3. Use appropriate model for task complexity
  4. Enable prompt caching for repeated contexts
  5. Set `max_tokens` appropriately
</Accordion>
</AccordionGroup>
